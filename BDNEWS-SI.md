## Deploying

Vercel project with the repository's `vercel.json` (build command `npm run build:full`), plus an
Upstash Redis database (`UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN`) and the data seeders
running on a schedule. See `SELF_HOSTING.md` for the data seeders and optional API keys.
- Live TV: Somoy TV, Jamuna TV, Channel 24, Independent TV, Ekattor TV and ATN News are the default
  Live News channels (`src/config/live-video-sources.ts`, `src/services/live-channels.ts`).
- News: 13 more Bangladeshi outlets (English and Bangla) in `shared/news-catalog.json`, on by default,
  with tiers, provenance, country tags and attribution rows. Upstream tests that pinned Dhaka Tribune,
  Prothom Alo and bdnews24 as opt-in were adjusted.
- Bangladesh News panel (`bangladesh`, right after Live News): stories from Bangladeshi outlets and
  stories about Bangladesh, gathered from every loaded news category (`src/config/bangladesh-news.ts`,
  `src/app/data-loader.ts`, `src/app/panel-layout.ts`).

## Sign-in (2026-11-20)
- Supabase Auth (project `bd-situation-intelligence`, ap-south-1). Settings in `src/config/auth.ts`.
- `login.html` + `src/login-main.ts`: sign in, create account, password reset.
- `middleware-auth-gate.ts`: on bdnews.si and this project's Vercel previews, dashboard page requests without a valid Supabase token (cookie `bdsi_at`) redirect to `/login.html`. The dashboard also checks the session in the browser (`src/services/bdsi-auth.ts`) because the offline cache can serve the page. Data APIs remain public.
- Command bar shows the signed-in email and a LOG OUT button.

## Bangladesh markets (2026-11-20)
- `api/bd-markets.js` (Edge): reads the Dhaka Stock Exchange live snapshot (dse.com.bd), Bangladesh Bank's daily Taka rates (bb.org.bd) and TCB's daily Dhaka retail price .xlsx (tcb.gov.bd), caching each (1 min / 30 min / 60 min). `api/_xlsx-lite.js` reads the .xlsx without dependencies.
- Panels `bd-dse`, `bd-taka`, `bd-bazaar` (`src/components/BdMarketsPanels.ts`), service `src/services/bd-markets.ts`.
- Command bar: DSE, TAKA and BAZAR function keys; ticker starts with DSEX, DS30, DSES and USD/BDT.
- Updated the panel-default snapshot lock in `tests/webmcp-dashboard.test.mts` for the added panels.

# BD Situation Intelligence logo

Wordmark: **BD** in Inter Display Black, an amber square on the baseline (`#FFA31A`), and *Situation Intelligence* in Inter Display Medium. All text is converted to outlines, so the SVGs need no fonts.

| File | Use |
|---|---|
| `logo-black.svg` / `logo-white.svg` | Horizontal logo for light / dark backgrounds |
| `logo-stacked-black.svg` / `logo-stacked-white.svg` | Stacked logo for square spaces |
| `icon.svg` | App icon and favicon (black tile) |
| `mark.svg` | "BD." mark alone, text in `currentColor` |

Rebuild with `python3 brand/make_logo.py <out-dir>` (needs `fonttools` and Inter Display installed). Inter is licensed under the SIL Open Font License 1.1.
